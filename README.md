# 学生教务信息管理系统  微信小程序

## 🚀 功能更新 (Feature Updates)

本项目已完成核心功能的开发，支持多角色（学生、教师、管理员）的差异化体验。

### 🔑 身份验证与用户体验
* **登录/注销**: 完整的登录逻辑，支持本地缓存用户信息；顶部状态栏提供便捷的注销功能。
* **角色识别**: 自动识别用户身份（学生/教师/管理员），并在界面顶部显示真实姓名与角色标签。
* **主页交互**: 
    * 顶栏显示用户信息。
    * 周次导航支持滑动 (`Swiper`) 和按钮点击切换。
    * 根据角色动态展示功能入口按钮。

### 🎓 角色专属功能

#### 👨‍🎓 学生 (Student)
* **查看课表**: 按周次查看个人课程安排，支持点击查看课程详情（时间、地点、教师）。
* **查成绩**: 专属“查成绩”入口，展示选修课程的学分与最终成绩，及格/不及格高亮显示。

#### 👩‍🏫 教师 (Teacher)
* **授课课表**: 查看个人的授课时间表。
* **我的课程**: 专属“我的课程”入口，列表展示所教授的课程名称及学分信息。

#### 🛡️ 管理员 (Admin)
* **系统状态看板**: 专属“系统状态”入口，提供可视化的数据仪表盘。
* **数据统计**: 实时展示系统内的注册用户数、在校学生数、教职工数、开设课程数及行政班级数。

### 🛠️ 技术细节
* **API 整合**: 所有数据均通过 HTTPS 请求对接后端 `MiniProgramApiController`。
* **UI 组件**: 使用原生 `Swiper`、`Scroll-View` 及 `Flex` 布局实现响应式界面。
